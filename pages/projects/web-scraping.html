Amazon Product Price Tracker

Automated pipeline that captures Amazon product titles, prices, and dates to monitor market changes without manual effort.

Core features

  • Scrapes key product fields from Amazon detail pages.
  • Structures output and stores entries in CSV for long-term tracking.
  • Supports repeated execution to grow a historical dataset over time.
  • Can be scheduled to run at custom intervals for proactive monitoring.

Stack

  • Python 3, BeautifulSoup, and Requests for acquisition.
  • Pandas for data cleaning and quick exploration.
  • CSV, OS, Time, and Datetime for file management and scheduling.
